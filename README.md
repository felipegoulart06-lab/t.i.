# Felipe Goulart – Desenvolvimento & Tecnologia

Site estático (um único `index.html`), sem build.

## Publicar na Vercel
1. Suba esta pasta para um repositório no GitHub.
2. Na Vercel: Add New > Project > importe o repositório.
3. Framework Preset: **Other**. Build Command e Output Directory: deixe vazios. Deploy.

Ou pela CLI, dentro desta pasta: `npx vercel --prod`.
